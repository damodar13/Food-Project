# 🍔 Food Project

A responsive food browsing and ordering web application built with React and Vite. 

## 🚀 Tech Stack
* **Frontend:** React.js, JavaScript, CSS
* **Build Tool:** Vite

## ⚙️ Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/damodar13/Food-Project.git](https://github.com/damodar13/Food-Project.git)

```

2. **Navigate to the project directory:**
```bash
cd Food-Project

```


3. **Install dependencies:**
```bash
npm install

```


4. **Run the development server:**
```bash
npm run dev

```



## 📂 Project Structure

* `src/`: Contains all React components (e.g., `App.jsx`, `main.jsx`), modular component folders, and CSS files.
* `public/`: Static assets that do not need to be processed by Vite.
* `index.html`: The main HTML entry point for the application.
